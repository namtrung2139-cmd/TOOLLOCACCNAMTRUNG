Mục 1 — Tổng Lọc

  • B1: Up file txt full info.
  • B2: Nhập 1 hoặc nhiều điều kiện (từ khóa, SS≥, SSS≥, Anime≥, tổng skin, tên skin cụ thể).
  • B3: Bấm LỌC NGAY — copy hoặc tải kết quả.

Mục 2 — Chuyển Đổi

  • Chuyển file full info → dạng tk:mk hoặc tk|mk.
  • Tự loại rác (FINAL=, Result=...).

Mục 3 — Cắt File

  • Chia file lớn thành nhiều file nhỏ theo số acc tuỳ chọn.

Mục 4 — Ghép File

  • Up nhiều file (tối đa 50), hệ thống cộng dồn thành 1 file tổng.
  • File càng lớn càng lâu, kiên nhẫn chờ.

Mục 5 — Lọc Acc Trùng

  • Up 1–50 file — hệ thống tự duyệt, chuyển về tk|mk.
  • Loại bỏ acc trùng, giữ 1 acc duy nhất.
  • Tra cứu lại thông tin acc trong file gốc.

Mục 6 — Text → File

  • Dán text → xuất ra TXT / PDF / DOCX nhanh chóng.
